# CPFC_Bot

Мини-приложение для Telegram: калории, белки, жиры, углеводы и цены готовой еды из магазинов (Милти, Перекрёсток) с оценкой полезности.

- Поиск по названию или цифрам штрихкода.
- Кнопка «Скан»: сканирование штрихкода камерой телефона.
- Фильтры по магазину, категории и оценке, сортировка по белку, калориям и цене.

Всё приложение — один файл `index.html`, опубликованный через GitHub Pages. Данные о блюдах и штрихкоды встроены в него; штрихкоды добавляет только владелец.

Оценка полезности ориентировочная и не заменяет совет врача. Данные взяты с сайтов магазинов и могут устареть.
